This code was for the analysis of collocated hourly precipitation and soil moisture data. The details of the data can be found at the Illinois State Water Survey site.
The hourly precipitation and soil moisture data used in this study are available by request 
to the Water and Atmospheric Resources Monitoring Program (WARM, https://warm.isws.illinois.edu/warm/contact.asp). 

If using this code for any work that gets published please cite this repository and the corresponding original article:
Straus, K., et al. "Uncertainty in Precipitation Effectiveness and Soil Moisture Recharge Heavily Reduced by Precipitation
Characteristics in the Midwest United State." (submitted) Water Resources Reseearch.
